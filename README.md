# 🍎 MacOS Portfolio

A modern **macOS-inspired Portfolio Website** built with **React**, **Vite**, and **SCSS**. This project recreates the look and feel of the macOS desktop while showcasing my portfolio, projects, skills, and resume.

---

## 🚀 Live Demo

👉https://mac-os-portfolio-qdz8.vercel.app/

---

## ✨ Features

- 🍎 macOS-inspired desktop interface
- 🖥️ Draggable application windows
- 💻 Interactive Terminal powered by Xterm.js
- 🎵 Spotify Player Window
- 📝 Markdown Notes Application
- 📄 Resume Viewer
- ⚡ Smooth window animations
- 🎨 Responsive UI
- 📱 Modern React Architecture

---

## 🛠️ Tech Stack

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/harishthecodertobe/MAC-OS-Portfolio.git
```

Go inside the project

```bash
cd MAC-OS-Portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

## 📦 Build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
